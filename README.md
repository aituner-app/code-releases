# AiTuner Code releases

Signed and notarized downloads of [AiTuner Code](https://aituner.app/code/), the coding agent that runs on the model
[aituner](https://aituner.app) runs on your Mac (Apple Silicon, macOS 14 or later), and the notes for every release:
see [Releases](../../releases).

- **Homebrew:** `brew install --cask aituner-app/tap/aituner-code` (also puts `aituner-code` on your PATH)
- **Disk image:** download `AiTunerCode_v<version>.dmg` from the latest release, open it and drag AiTuner Code to
  Applications.
- Every release lists SHA-256 checksums in `SHA256SUMS`.

AiTuner Code needs aituner running on the same Mac. Bugs go to [aituner-app/issues](https://github.com/aituner-app/issues).
